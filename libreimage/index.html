Vie privée

Les métadonnées (position GPS, appareil, date de prise de vue) sont toujours retirées des images produites. Celles trouvées dans l’original sont signalées sur chaque image.

À propos

LibreImage allège tes images et retire les informations cachées qu’elles contiennent, sans les envoyer sur un serveur.

Confidentialité

Les images sont traitées dans ton navigateur. Elles ne quittent jamais ton appareil.

Quel format choisir ?

JPEG pour les photos, WEBP pour le web (plus léger à qualité égale), PNG pour les captures d’écran, les logos et la transparence.

Pourquoi retirer les métadonnées ?

Une photo prise au téléphone contient souvent la position exacte où elle a été prise, le modèle d’appareil et l’heure. Ces informations restent dans le fichier quand tu le partages.
